System Architecture & Technical Processing Flow

Complete end-to-end pipeline explanation from video upload to ad placement

PRODUCER-CONSUMER PARALLEL STREAMING ARCHITECTURE Zero Disk Bottleneck • Real-Time Decoupled Pipeline
Input Stream MP4 Video H.264 Demuxing
Worker A (Producer) ThreadedFrameReader Decodes to RAM Queue (48 frames)
Worker B & C (Consumer) Neural / OCR Quads & Tracker YOLOv8 + 3D Mesh in Parallel
Post-Stream Optimizer Co-Spatial Merge & Scoring 1 Billboard Placement (30.4s)
1 Video Ingestion & Codec Demuxing
Input Phase

The video is streamed to the server and decoded using OpenCV cv2.VideoCapture at native FPS. Frame dimensions and metadata are normalized, and the output is converted to universal H.264 (yuv420p) for seamless HTML5 browser playback.

Flow: Raw MP4/MOV → OpenCV Stream → Browser H.264
2 Worker A: Asynchronous Frame Extractor [Producer]
Parallel Producer

Dedicated background thread continuously decodes frames into a prefetch RAM queue without writing raw images to disk. Uses adaptive keyframe striding (stride = 3), overlapping frame extraction 100% with downstream neural inference.

Flow: Producer Thread → Thread-Safe RAM Buffer (48 frames) → Zero Disk IO
3 Worker B: Neural & OCR Surface Quad Detector [Consumer]
Parallel Consumer

Consumes decoded frames from the queue concurrently in parallel. YOLOv8 open-vocabulary & OCR/text boundary models locate planar candidate surfaces (billboard, sign, wall, transit bus/car flank) and fit projectively perspective 3D quads P1(TL), P2(TR), P3(BR), P4(BL).

Flow: Stream Queue → Parallel Neural/OCR Inference → 3D Planar Quad Mesh
4 Worker C: Continuous Spatial Tracker & Occlusion Reasoner
Tracking Stream

Tracks candidate surfaces across frames in lockstep. Features spatial re-identification memory (120-frame window) and 55-frame smooth coasting to prevent momentary dropouts, while subtracting dynamic occluder masks (pedestrians, vehicles).

Flow: Centroid IoU → Re-ID Memory Revive → Smooth Coasting → Occlusion Mask
5 Co-Spatial Billboard Consolidation & Disjoint Slots
Optimizer Phase

Post-stream consolidation algorithm compares all tracklets pairwise: surfaces occupying the same physical screen space are merged into ONE single continuous placement spanning the full video, followed by disjoint non-overlapping timeline slot partitioning.

Flow: Fragmented Tracklets → Co-Spatial Merge → Unified Placement → Non-Overlap Slots
6 Multi-Factor Ranking & 3D Ad Placement
Output Phase

Multi-factor ScoreEngine evaluates duration, canvas area, occlusion resistance, jitter stability, and geometry. The optimal Rank #1 space is highlighted with a neon green 3D selected ad square with orientation triad and depth badges, exported to CSV & JSON.

Flow: Score Formulation S → Rank 1 Placement → 3D Neon Target Square (P1-P4)
Scoring Formulation: S = w_dur·S_dur + w_area·S_area + w_occ·S_occ + w_stab·S_stab + w_geom·S_geom
